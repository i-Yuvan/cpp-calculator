***C++ Calculator***

A basic calculator developed using C++.

--- Features
1. Four basic arithmetic operations
2. Repeated calculations
3. Division-by-zero protection
4. Invalid operator handling

--- How to Run
Compile `calculator.cpp` using a C++ compiler.
For example, with g++:
```bash
g++ calculator.cpp -o calculator
```

Run on Windows:
```bash
.\calculator.exe
```

--- Concepts Used
Variables, loops, switch statements,
input/output and conditional statements.
