# C++ Calculator

A basic calculator developed using C++.

## Features
- Four basic arithmetic operations
- Repeated calculations
- Division-by-zero protection
- Invalid operator handling

## How to Run
Compile `calculator.cpp` using a C++ compiler.

For example, with g++:
```bash
g++ calculator.cpp -o calculator
```

Run on Windows:
```bash
.\calculator.exe
```

## Concepts Practised
Variables, loops, switch statements,
input/output and conditional statements.
